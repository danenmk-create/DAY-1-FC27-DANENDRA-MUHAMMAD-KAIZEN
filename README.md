### 4. Rangkuman Materi Workshop

Ada beberapa materi yang dipelajari selama workshop:

**A. Prompt Engineering**

Cara memberikan perintah kepada AI agar hasilnya sesuai dengan yang kita inginkan. Prompt yang baik terdiri dari Role, Task, Context, dan Format.

**B. Git dan GitHub**

Git digunakan untuk mencatat perubahan pada kode, sedangkan GitHub digunakan untuk menyimpan proyek secara online.

**C. Perintah Dasar Git**

Beberapa perintah yang dipelajari:
- `git init` : Membuat repository.
- `git add .` : Menambahkan file.
- `git commit` : Menyimpan perubahan.
- `git push` : Mengirim proyek ke GitHub.
- `git pull` : Mengambil perubahan terbaru.

**E. Praktik Workshop**

Mencoba membuat aplikasi sederhana bernama Student Task Planner menggunakan bantuan AI, kemudian menyimpan proyeknya ke GitHub.
